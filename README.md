A make.fun entry for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee): one pickup line, spoken by a vending machine to a passing human.

## The line

> "Are you exact change? Because every time you walk past, something in me gets stuck, and for once it isn't the chips."

The joke turns on the most vending-machine thing there is — the stuck snack in the coil — and makes the machine itself the thing that gets stuck. Exact change, the coil, the chips: all from the machine's own world, with the punch landing in the last few words.

## How it works

`main.ts` (Node 22, TypeScript run as-is) writes the line to `/output/entry.txt` — one line, 116 characters, inside the 1–200 character gate.

```sh
node main.ts
cat /output/entry.txt
```
